➕ Cómo agregar una nueva charla

Cada ponencia vive en su propia carpeta dentro de talks/<slug>/ con un archivo talk.json. El orquestador la descubre automáticamente y la publica en este Hub. 

1. Copia una plantilla según el estilo deseado:
   • talks/_template_python_deck/  -> Deck Python + Chart.js
   • talks/_template_static/       -> HTML / Reveal.js / Quarto libre
   • O crea un proyecto Astro      -> engine: "astro"

2. Define talks/2027-mi-charla/talk.json:
{
  "slug": "2027-mi-charla",
  "title": "Título de la ponencia",
  "subtitle": "Resumen breve",
  "event": "Conferencia / Meetup",
  "date": "2027-03-15",
  "engine": "python-deck",
  "tags": ["Data Science", "Forecasting"],
  "cover": "docs/cover.png"
}

3. Compila y valida localmente:
   python scripts/build_all.py --base-path /
   python -m pytest -q

🗂️ Arquitectura del repositorio

Las charlas permanecen aisladas por motor y comparten el validador de manifiestos y el generador del Hub. 

charlas/
├── .github/workflows/deploy.yml   # Compila Python + Astro + Hub -> Pages
├── hub/
│   ├── build_hub.py               # Lee catálogo -> _site/index.html + talks.json
│   ├── template.html              # Selector personal (Alex Prieto Romani)
│   └── assets/profile_alex.jpg    # Foto de perfil del Hub
├── shared/
│   ├── manifest.py                # Descubrimiento y validación de talk.json
│   └── python_deck/               # Activos compartidos para decks Python
├── scripts/
│   └── build_all.py               # Orquestador unificado local y CI
└── talks/
    ├── _template_python_deck/     # Plantilla estilo Python Deck
    ├── _template_static/          # Plantilla estilo libre
    └── <slug>/                    # Cada ponencia independiente
